# FrameFlow Flutter Demo

基于图片需求表实现的 Flutter 移动端原型，覆盖：

- 首页：拍照投屏、相册选图、权限检查、蓝牙设备切换、投屏流程预览
- 我的：邮箱验证码登录、个人信息、我的相册、我的设备、投屏管理、操作指南、设置
- 设备管理：设备连接、名称编辑、SN 码录入、所有者 / 使用者切换、一键清空、轮播模式
- 设置：关于我们、联系方式、隐私政策、用户协议、语种切换、退出登录、用户注销

## 运行

```bash
flutter pub get
flutter run
```

## 当前实现说明

这是一个可运行的业务原型，重点完成了表格里描述的核心流程与界面组织：

- 投屏流程：选择图片 -> 选择设备 -> 预览处理尺寸 -> 确认投屏
- 内存满处理：写入失败记录，并引导到“我的”模块处理
- 我的相册：仅显示成功上传至设备的照片，支持多选删除与再次投屏
- 设备管理：支持容量、电量、角色、SN、轮播、一键清空
- 语言切换：提供中文 / English / 日本語 三种界面切换

当前仓库未接入真实硬件与后端，以下能力仍为本地模拟流程：

- 手机相机与系统相册真实调用
- 蓝牙扫描 / 配对 / 通信
- 邮箱验证码真实下发
- 云端账号、图片上传、设备存储同步

## 鸿蒙打包

本仓库目前只有 `android/` 和 `ios/` 平台目录。要实际生成鸿蒙 `HAP` 包，还需要切到 OpenHarmony Flutter 工具链，并为项目生成 `ohos/` 平台目录。官方 OpenHarmony Flutter README 提供的命令路径是：

- `flutter create --platforms ohos <projectName>`
- `flutter build hap --release`

如果本机已经安装 OpenHarmony Flutter SDK，也可以在当前工程目录补齐 `ohos/` 平台后继续适配。
