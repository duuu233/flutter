# XT IoT 平台 + WiFi 版 · 功能清单（一期交付）

> 版本：v6.0　日期：2026-09-20  
> 说明：本清单为**一期交付范围**，依据固件协议 V1.3.1 编写，供确认。

---

## 一、IoT 平台

| # | 功能 | 说明（做什么） |
|---|---|---|
| 1 | 设备接入与连接管理 | 相框接入服务器；含 Topic 规范、连接鉴权（usr/pwd）、上下线管理 |
| 2 | 设备管理 | 后台可查看、搜索、管理所有相框 |
| 3 | 设备影子 | 缓存相框**最新状态**（电量、信号、TF 卡、版本、方向） |
| 4 | 指令可靠机制 | 离线指令缓存、上线补发、超时重试、回执关联（`msgid`/`ack_msgid`）|
| 5 | **指令下发通道**（IoT → 设备） | 向相框下发下行指令（详见「二」） |
| 6 | **设备上报通道**（设备 → IoT） | 接收相框上报（详见「二」），据此维护在线状态与设备影子 |
| 7 | 配网支持 | 蓝牙配网（BluFi）下发 WiFi 信息 + 服务器参数（`mqtt_config`、国家码） |
| 8 | 文件分发 | 向相框下发图片 / 固件的**下载地址**，供其自行下载 |
| 9 | 固件升级下发 | 按协议下发固件下载地址（`ota` / `fpga`），并接收升级结果 |
| 10 | 数据存储 | 存储设备、指令、状态等业务数据 |
| 11 | 日志 | 设备 / 平台运行日志（问题排查） |
| 12 | **业务接口（REST）** | 提供接口供 App / 小程序 调用：设备管理、投屏、轮播、升级、状态查询等 |
| 13 | **实时推送（WebSocket）** | 设备状态 / 指令回执实时推送给终端 |

## 二、依据协议设计的功能（**标准协议全量列出，可按需调整**）

> 依据《XT 电子纸相框通讯协议 V1.3.1》及乐鑫 BluFi 配网协议**全量列出**，供确认，实际**可按需裁剪**。

### 2.1 MQTT 指令（设备在线运行时）

| 下发指令（IoT → 设备） | 功能 | 上发指令（设备 → IoT） | 功能 |
|---|---|---|---|
| `login_ack` | 登录应答 | `login` | 登录上报 |
| `heart_ack` | 心跳应答 | `heart` | 心跳上报（电量 / 信号 / TF / 版本等） |
| — | — | `uptag` | 蓝牙标签上报 |
| `ota` | 固件升级（主控固件，下发下载地址） | `ota_ack` | OTA 结果 |
| `fpga` | FPGA 升级（FPGA 固件，下发下载地址） | `fpga_ack` | FPGA 结果 |
| `wifimode` | WiFi 模式（实时 / 定时 / 休眠） | `wifimode_ack` | WiFi 模式结果 |
| `wifi_sleep` | 定时休眠 | `wifi_sleep_ack` | 休眠配置结果 |
| `device_config` | 设备配置 | `device_config_ack` | 设备配置结果 |
| `play` | 播放单图（投屏） | `play_ack` | 播放结果 |
| `strategy` | 轮播策略（含 Bin） | `strategy_ack` | 轮播结果 |
| `strategy_stop` | 暂停轮播 | `strategy_stop_ack` | 暂停结果 |
| `play_tf` | 播放 TF 卡内图片（设备本地图，App 不单独暴露） | `play_tf_ack` | 播卡结果 |
| `clean_tf` | **清空设备 TF 卡**（清本地存储，与"云端删图"无关） | `clean_tf_ack` | 清空结果 |
| `down_int_img` | 下载内置图片（设备出厂 / 内置图，后台下发） | `down_int_img_ack` | 内置图结果 |
| `image_refresh` | 刷新图片（通知设备清空 TF 卡内容并重刷） | `image_refresh_ack` | 刷新结果 |
| `country` | 国家码变更 | `country_ack` | 国家码结果 |
| `shutdown_ack` | 关机应答 | `shutdown` | 关机通知 |

### 2.2 配网功能（蓝牙 BluFi）

> **统一走蓝牙配网，不使用热点（AP）配网。**

| 类别 | 功能 |
|---|---|
| **WiFi 扫描** | 扫描并获取附近 Wi-Fi 热点列表 |
| **下发 Wi-Fi 信息** | 下发 SSID、密码、BSSID |
| **安全协商** | 设置安全模式（密钥协商 + 数据加密） |
| **连接控制** | 连接 AP / 断开 AP |
| **状态回传** | Wi-Fi 连接状态报告（含连接状态、失败原因、RSSI） |
| **其他** | 获取版本信息、异常报告 |
| **XT 自定义消息** | `mqtt_config`（下发 MQTT 服务器参数）、`wifi_set_country_code`（设置 WiFi 国家码） |

## 三、终端（App / 小程序）

| # | 功能 | 说明（做什么） |
|---|---|---|
| 1 | 搜索页 | 一次搜索同时发现蓝牙和 WiFi 相框 |
| 2 | 设备列表 | 列表区分蓝牙 / WiFi 设备，展示在线状态 |
| 3 | 设备绑定 / 解绑 | WiFi 相框的绑定与解绑 |
| 4 | 配网引导 | 引导完成蓝牙配网 / 重新配网（蓝牙扫描 → 选 WiFi → 输密码 → 下发） |
| 5 | **投屏** | 单图投屏、**批量投屏**（选择设备 + 图片下发） |
| 6 | **轮播管理** | 设置轮播（顺序 / 随机）、查询当前轮播、**暂停轮播** |
| 7 | **屏幕刷新** | 刷新屏幕（通知设备清空 TF 卡并重刷） |
| 8 | **照片管理** | 删除照片（**云端删除**；删除后设备自动切换显示其他图 / 默认图，**不动 TF 卡**） |
| 9 | **图源切换** | 切换设备播放来源：**APP 投屏** / **TF 卡播放** |
| 10 | **WiFi 模式设置** | 设置设备联网模式（实时 / 定时 / 休眠） |
| 11 | **定时休眠设置** | 设置设备定时休眠（省电） |
| 12 | **固件升级** | 检查固件版本、发起升级、查看升级结果 |
| 13 | **设备信息查询** | 电量查询、固件版本查询、设备 ID 查询 |
| 14 | **实时状态** | 设备状态 / 指令回执**实时更新**（WebSocket） |
| 15 | 图片方向适配 | 按机型适配图片方向（竖屏 / 横屏） |

## 四、管理后台（IoT 平台管理能力集成进现有后台）

| # | 功能 | 说明（做什么） |
|---|---|---|
| 1 | 产品类型 | 产品列表增加「类型」（蓝牙 / WiFi）用于区分 |
| 2 | WiFi 设备管理 | 新增菜单：设备列表、详情、绑定 / 解绑管理 |
| 3 | 设备状态查看 | 查看设备实时状态（影子：在线、电量、信号、版本等） |
| 4 | 日志查看 | 分类日志：入网 / 配网、上下线、指令、OTA、异常 |
| 5 | 设备监控统计 | 在线率、活跃设备等运营统计 |
| 6 | 固件管理 | 复用现有（上传 / 版本）；支持**主控固件与 FPGA 固件**，IoT 下发下载地址 |
| 7 | 图片方向配置 | 复用现有配置（方向 / 旋转度数） |
