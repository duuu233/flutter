# BLE 连接与设备身份规则

> 文档类型：Architecture Decision  
> 状态：Active  
> 最后核验：2026-07-30  
> 维护责任：BLE、设备列表/详情、绑定与投屏维护者  
> 事实来源：`ble_controller.dart`、`serial_match.dart`、`device_ble.dart`、
> `ble/ble_direct_connect_cache.dart`

## 1. 不变量

1. App 同一时刻只认领一个活动物理连接。
2. 用户点击的后端设备记录是本次操作的目标，异步过程中不得静默切换到另一条记录。
3. 设备显示名称不是物理身份，不能参与连接或复用判定。
4. 广播 4 字节短 ID 和屏幕型号只能筛选候选，不能完成最终验身。
5. 建立 GATT 后必须读取 0x01 完整 ID，与目标后端记录做最终核对。
6. 错误候选必须断开、排除其 `remoteId`，然后继续扫描剩余候选。
7. 后端设备记录、绑定入库和活动会话认领都必须使用完整 6 字节 ID；历史短 ID
   记录必须删除后重新绑定，不再兼容。

## 2. 身份数据

| 数据 | 来源 | 用途 | 可信度 |
| --- | --- | --- | --- |
| 后端设备 ID | UserProduct 记录 | 用户选中的目标身份 | 必须是完整 6 字节 |
| 广播短 ID | 厂商广播数据 | 扫描候选筛选 | 可能在同批次设备重复 |
| 0x01 完整 ID | 建连后设备指令 | 最终物理身份 | 当前客户端最可靠证据 |
| 屏幕类型码 | 后端/广播/0x01 | 防跨型号串台 | 双方已知且不同则直接拒绝 |
| `remoteId` | BLE 平台 | 排除错误物理候选 | 只在当前扫描环境内使用 |
| 设备名称 | 用户可编辑字段 | 展示 | 不得用于验身 |

序列号归一化规则：移除 `:`、`-`、空格并转大写。稳定身份必须是 12 个十六进制字符，
且不能是全 `0` 或全 `F`；展示和绑定入库统一为 `AA:BB:CC:DD:EE:FF`。

## 3. 匹配规则

### 候选匹配

`serialsMatch` 只用于广播短 ID 与长 ID 之间的兼容匹配：

- 完全相等：接受。
- 长度相同但内容不同：拒绝。
- 长度不同：短值至少 8 个十六进制字符，且必须是长值前缀或后缀。
- 任意位置 `contains` 不允许。

屏幕类型双方均已知且不同，候选直接拒绝。

### 稳定身份集合匹配

`serialSetsMatch` 只保留两侧的完整 6 字节 ID 并求精确交集。共享短 ID
不能覆盖完整 ID 不同这一事实，也不能独立完成判重。

### 建连后最终验身

`verifiedDeviceSerialMatch(expected, actual)`：

- 后端目标和 0x01 返回值都必须是有效的完整 6 字节 ID。
- 两者归一化后必须精确相等。
- 后端短 ID、全 0、全 F 或非十六进制值一律拒绝。
- 验身失败必须释放 GATT，不得把设备登记为活动会话。

### 活动会话复用

`sessionSerialsMatch`：

- 后端目标与活动会话都必须已登记相同完整 ID。
- 仅共享广播短 ID 不足以复用会话。
- 复用成功仍需保证屏幕类型不冲突。

## 4. 连接流程

```text
快照用户目标设备
  → 若活动会话完整身份匹配则复用
  → 快路径①：系统已连接表(systemDevices[FF00]) 按广播名白名单筛出相框候选，直接建连
  → 快路径②：本机直连缓存命中则按上次 remoteId 短超时(3s)直连，跳过整段扫描
  → 完整扫描（广播名白名单 + 弱信号闸）
  → 短 ID + 屏型筛候选
  → 停扫沉淀(settleAfterScan) 后连接候选 GATT
  → 发现服务/特征并订阅通知
  → 读取 0x01 完整 ID
  ├── 匹配：登记完整身份、写入直连缓存、读取设备信息、发布连接状态
  └── 不匹配：断开、排除 remoteId、删除该设备直连缓存、继续扫描
```

两条快路径都没有广播厂商数据，**身份完全由 0x01 完整 ID 提供**，与扫描路径同一把尺子；
广播短 ID 本来就只能筛候选、不能验身，因此跳过扫描不降低身份安全性。任一快路径失败都必须
静默回落完整扫描，不得改变原有失败语义与错误文案。

连接失败路径必须回收物理连接、通知订阅、保活服务、租约和 UI 状态，避免设备被残留 GATT
占用后停止广播。

### 直连缓存

- 键为 0x01 完整 6 字节 ID（归一化），值为本机上次验身通过的 `remoteId`。
- **只存本机**（`SharedPreferences`）：`remoteId` 是「设备 × 手机」的函数，Android 是射频 MAC、
  iOS 是本机系统给外设生成的 UUID，跨手机共享必然连不上还白等。
- 只有 0x01 验身通过才写入；赌不中、验身串台、删除设备记录时删除该键。
- 连续 2 次「直连失败但随后扫描成功」即在本进程内停用快路径，避免在不支持不扫描直连的
  平台上每次复连白花探测超时。

### 提速与弱信号参数

| 参数 | 值 | 位置 | 作用 |
| --- | --- | --- | --- |
| 建连超时阶梯 | 5s → 8s | `FrameBleClient.connectAttemptTimeouts` | 首次快速试错，末次耐心等弱信号的 CONNECT_IND |
| 建连退避 | 400ms | `connectRetryBackoff` | 让底层清干净半连状态再试 |
| 直连探测超时 | 3s | `directConnectProbeTimeout` | 快路径「赌一把」的上限 |
| Android autoConnect 兜底 | 8s | `androidAutoConnectFallback` | 常规建连全失败后的弱信号唯一有效手段 |
| 停扫沉淀 | 120ms | `scanSettleDelay` / `settleAfterScan` | 扫描与建连抢同一路射频 |
| 连接信号闸 | -70dBm / 最多等 1.5s | `BleController.weakSignalRssi` / `weakSignalWait` | 不抢窗口里最差的第一帧；等满照常连 |
| 建连后高优先级窗口 | 2s | `postConnectFastWindow` | 首屏 0x01/0x04 读完再回落省电档 |
| Android 起扫配额 | 5 次 / 30s，触顶最多等 10s | `FrameBleClient._awaitScanStartSlot` | 越限会被系统静默降级成「整窗搜不到」 |
| 同候选失败容忍 | 2 次 | `_maxConnectFailuresPerCandidate` | 连接失败 ≠ 不是这台，重扫拿新句柄再连 |

规则：**信号弱只能推迟连接、绝不能阻断连接**；等满窗口无论多弱都必须发起连接。
连接策略一律使用原始 RSSI，与保守下调过一级的展示档位（`rssiToSignalLevel`）互不牵连。

## 5. 单连接与状态展示

- `BleController` 是唯一 BLE 会话门面，页面不得直接持有 `FrameBleClient`。
- 连接另一设备前先结束旧会话；断开回调统一清理序列号、设备信息、上传状态和前台服务。
- 页面“已连接”只认 `BleController` 当前活动会话与目标完整身份，不认历史布尔值。
- 列表、首页和详情的连接标识必须由同一活动会话派生。
- 破坏性操作在入口快照 deviceId，全流程只对该目标执行。

## 6. 电量规则

- 电量统一通过 `0x04` 获取；`0x01` 中的电量字段不再写入页面状态，避免形成双数据源。
- 同一完整设备 ID 的有效读数缓存 15 秒；窗口内直接复用。
- 超过 15 秒后在后台读取真机并原位更新，普通页面刷新不等待电量读取。
- 同一设备的并发刷新共享一个在途请求，不能重复发送 `0x04`。
- `0..100` 均为有效值，`0%` 不能被当成空值。
- 普通页面/列表刷新不能先把已知电量清零。
- 新读数成功时原位更新；读取失败或响应非法时保留旧值。
- 从未成功读取时显示 `--`；设备未连接时隐藏电量，但缓存值不因一次断线或网络刷新丢失。
- 最终设备信息必须来自已通过完整 ID 验身的会话。

## 7. 生命周期

- 前台连接时启动 Android 连接保活服务。
- App 切出但屏幕仍亮：BLE 宽限 15 分钟。
- 息屏：BLE 宽限 30 分钟。
- 图传、连接和 OTA 属于活跃任务，租约不得在任务中途回收连接。
- 断开或租约到期后停止前台服务，使进程恢复可回收状态。

## 8. 验证

自动测试至少覆盖：

- 同长度完整 ID 不同，即使共享短 ID也必须拒绝。
- 完整 ID 相同允许复用。
- 后端短 ID、全 0、全 F 与非法格式全部拒绝。
- 屏幕类型冲突拒绝。
- 共享短 ID 的 A/B 两台设备：点击 A、先扫到 B 时必须断开 B 并继续找到 A。
- 电量 `0%` 可缓存；15 秒内不重复读取；过期并发只读一次；失败保留旧值。
- 直连缓存只接受完整 6 字节 ID 作键，短 ID/全 0/全 F/空句柄一律不写；磁盘脏数据读回时过滤；
  存储损坏不抛错且不影响后续写入。
- 连接信号闸：够强立刻连、读不到 RSSI 立刻连、等满窗口再弱也必须连。

对应单测：`test/serial_match_test.dart`、`test/device_battery_cache_test.dart`、
`test/ble_connection_lease_test.dart`、`test/ble_direct_connect_cache_test.dart`、
`test/ble_signal_level_test.dart`。

真机回归（自动测试覆盖不到，发版前必做）：

- Android 弱信号（-70~-85dBm）复连成功率，含 `autoConnect` 兜底命中后无幽灵连接残留。
- 半分钟内连点 6 次以上设备，不得出现「忽然全都搜不到」。
- 设备被系统层占着（另一 App 连着/杀进程后残留）时能走系统已连接表兜底。
