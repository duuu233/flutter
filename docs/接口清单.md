# 接口清单（App / BoltStar）

> 来源：产品《接口清单02.png》 + 后端 Swagger（https://api.boltfox.cn/swagger-ui.html）对照整理。
>
> 适用系统：`App IOS` / `App Android`。与小程序共用同一套后端接口，差异在登录方式与平台专属接口。
>
> App 适配规则：
> - 登录走 **邮箱验证码注册 / 邮箱密码登录**，**不接入** `setWechatAppLogin`（微信一键登录）。
> - **保留** App 版本更新、安卓下载接口（小程序跳过的，App 需要）。
> - PC 注销 `userOffPC` 跳过。
> - 公共参数 `device` / `terminal` / `language` / `userToken` 通过 headers 传递；App `terminal`：iOS=1、Android=2（**待后端确认**，见 `lib/src/network/api_config.dart`）。
> - 接入状态：✅ 接口层已接入（`lib/src/network/boltfox_api.dart`） · ⛔ App 跳过 · ➖ 无对应接口（纯前端 / 端能力）

## App 跳过清单

| 接口 | 摘要 | 跳过原因 |
| --- | --- | --- |
| `POST /Client/User/setWechatAppLogin` | 微信小程序一键登录 | App 走邮箱登录 |
| `POST /Client/User/userOffPC` | 用户注销 PC 版 | PC 版接口 |

## 与小程序清单的差异

- App **接入**了 `getLastVersion`、`getAndroidDownload`（小程序跳过）。
- App **跳过** `setWechatAppLogin`（小程序接入）。
- 其余基础公共 / 产品 / 用户（邮箱体系）/ 设备接口两端一致，仅 `terminal` 取值不同（小程序=3，App iOS=1/Android=2，待后端确认）。

## 网络层结构（lib/src/network）

| 文件 | 职责 |
| --- | --- |
| `api_config.dart` | baseUrl、超时、terminal |
| `api_session.dart` | userToken / 语言码 / device 会话态 |
| `api_exception.dart` | 统一异常（isAuthError 判定 401/406） |
| `api_client.dart` | header 注入 + retCode/retData 解析 + JSON/上传 |
| `boltfox_api.dart` | 业务接口（基础/产品/用户/设备） |
