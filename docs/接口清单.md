# 接口清单（App / BoltStar）

> **📌 文档维护约定**：本文档随代码演进——**每次修复问题 / 改动后，务必回到对应 .md 在文末「操作日志」追加一条**（日期 + 改了什么 + 对应代码符号/文件），防止文档滞后于代码、误导后续把已修的 bug 又改回去。


> 来源：产品《接口清单02.png》 + 后端 Swagger（https://api.boltfox.cn/swagger-ui.html）对照整理。
>
> 适用系统：`App IOS` / `App Android`。与小程序共用同一套后端接口，差异在登录方式与平台专属接口。
>
> App 适配规则：
> - 登录支持 **邮箱验证码注册 / 邮箱密码登录**，以及微信开放平台**移动应用微信登录**。
> - **保留** App 版本更新、安卓下载接口（小程序跳过的，App 需要）。
> - PC 注销 `userOffPC` 跳过。
> - 公共参数 `device` / `terminal` / `language` / `userToken` 通过 headers 传递；App `terminal`：**Android=1、iOS=2**（小程序=3）。已按 swagger 核实（20 处定义一致：`1=安卓客户端,2=苹果客户端,3=小程序`），见 `lib/src/network/api_config.dart`。⚠️ 2026-07-19 前这里写反了，导致 iOS/安卓互相拿到对方的版本号。
> - 接入状态：✅ 接口层已接入（`lib/src/network/boltfox_api.dart`） · ⛔ App 跳过 · ➖ 无对应接口（纯前端 / 端能力）

## 与小程序清单的差异

- App **接入**了 `getLastVersion`、`getAndroidDownload`（小程序跳过）。
- App 与小程序均调用 `setWechatAppLogin`，但 App 走开放平台移动应用 OAuth code，小程序走手机号授权数据。
- 其余基础公共 / 产品 / 用户（邮箱体系）/ 设备接口两端一致，仅 `terminal` 取值不同（小程序=3，App **Android=1/iOS=2**，已按 swagger 核实）。

| 文件 | 职责 |
