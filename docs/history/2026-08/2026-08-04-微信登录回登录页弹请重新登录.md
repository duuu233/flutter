# 安卓微信快捷登录「回登录页弹请重新登录」定位：后端 406，不是微信授权失败

> 文档类型：Change Record
> 状态：Current
> 日期：2026-08-04
> 范围：Flutter APP（登录页微信入口、微信登录失败提示）
> 权威运行手册：`../../integration/WECHAT_LOGIN_SETUP.md`（结论与复现命令同步在第一节与 5.1）
> 状态说明：客户端改动已落地，**未跑 analyze/test、未编译、未真机**（本机无 Flutter SDK）

## 现象

安卓端点登录页的微信快捷图标 → 跳到微信授权界面 → 选择后跳回登录页 → 弹「请重新登录」。
直觉判断是「没有授权成功」，排查方向自然指向 fluwx、AppID、签名、`WXEntryActivity`。

## 根因：那句提示根本不是微信报的

「请重新登录」在客户端只有两个出处，微信 SDK 那条是「微信授权已**超时**，请重新登录。」
（2 分钟后才会出现，且文案不同）。真正命中的是另一条：**后端 retMsg**
`请重新登录！` 经 `AppL10n._serverMessages` 重译成「请重新登录」后弹出。

curl 直打生产复现（不带 `userToken`）：

```bash
curl -s -X POST "https://api.boltfox.cn/Client/User/setWechatAuthorizLogin?terminal=1&language=2" \
  -H 'content-type: application/json' -H 'terminal: 1' -H 'language: 2' \
  -d '{"code":"probe"}'
# {"retCode":406,"retMsg":"请重新登录！","retData":null}
```

同样不带 `userToken` 的对照组全部正常进入业务逻辑：`userLogin` → `Email does not exist`；
`userRegister` → `Please enter the correct email address`；`setWechatAppLogin` →
`40029, errmsg`（说明它确实拿 code 找微信换过）。把 `terminal` 改 3、query 全去掉、
`userToken` 传空串或垃圾值、body 连 `code` 都不发——`setWechatAuthorizLogin` 一律回同一条 406，
即请求在业务逻辑之前就被拦截器挡了。

**结论：微信授权是成功的，code 已经拿到，死在后端换 token 这一步。**
`/Client/User/setWechatAuthorizLogin` 没进后端免登录白名单，而它按 swagger 就是登录接口
（响应 `BaseOutput«UserInfoDetailApiOut»`，本该返回 `userToken`/`jwtToken`）。
调用它的用户按定义没有 `userToken`，**客户端无解，必须后端放行**。

## 客户端改动（不能修好登录，但要让错误说真话、且看得见）

| 文件 | 改动 |
| --- | --- |
| `lib/src/state.dart` | `loginWithWeChatCode` 单独接 `ApiException`：登录接口**自身**的 401/406 不再走 `_apiFailure`（不当成会话过期、不透传「请重新登录」），改为带 retCode + 原始 retMsg 的说明性提示 |
| `lib/src/features/account/data/wechat_authorization_client.dart` | 新增 `kWeChatLoginDiagnostics`（`--dart-define=WECHAT_LOGIN_DIAGNOSTICS`，默认开） |
| `lib/src/features/account/presentation/auth_page.dart` | 新增 `_withDiagnostics`：微信登录失败的 toast 追加原始细节（SDK 错误类别 / 后端 retCode+retMsg / 预期外异常原文）；成功取到 code 时附带「微信 code 已取得(N 位)」；`catch (_)` 改为记录异常与堆栈 |
| `test/wechat_login_test.dart` | 新增用例：后端 406 时提示不得等于「请重新登录」，且必须带上 `406` |

### 为什么细节要进 toast，而不是只进 debugPrint

微信按开放平台登记的**签名**校验；2026-08-05 起 debug/profile/release 已统一使用正式签名，
三种包都能走授权链路。但 release 包里 `kDebugMode` 恒 false，`debugPrint` 除 `adb logcat` 外没有出口。
排查期屏幕上只剩一句
「微信授权失败，请稍后重试」，等于没有现场——这次的误判正是这么来的。
上线前用 `--dart-define=WECHAT_LOGIN_DIAGNOSTICS=false` 关掉即可恢复纯净文案。

### 为什么不顺手改回 `setWechatAppLogin`

它是小程序的「授权手机号一键登录」（入参还要 `wxEncrypData`/`wxIvData`），大概率用的是
小程序的 AppID/AppSecret，移动应用 OAuth 的 code 送过去只会换来 40029/40163，
且 code 一次性、试错即作废。不做这种投机降级。
