## 1. AI助手入口开放（需求 1）

### 为什么 iOS 看不到——**不是 iOS 的问题**

入口由 `features/ai/ai_entry.dart` 的 `kAiEntryEnabled` 一个 const 控制，**两端同值**，
此前是 `false`，所以 Android 正式包同样看不到。屏蔽期唯一入口是「硬件联调调试台」底部暗门
（口令 `8866`），而调试台在 `routes/app_routes.dart` 里被 `kDebugMode` 挡着——
**正式包里连暗门都不存在**，于是「打包成 App 之后整块 AI 消失」。

小程序侧的同名开关早已翻开（`custom-tabbar.js` 注释：「AI 对话已正式开放」），
两端因此错位。

### 改动

- `kAiEntryEnabled` 改 `true`，注释改写为「保留开关只为灰度/应急下线」，并写明
  **正式包关掉开关 = 整块功能不可见**（暗门不算退路）。
- 底栏中间加一格「AI助手」，点它走 `openAiChat`（与小程序 `goAi` 同一目标页，
  含「接着上次那一页」的 `sessionId` 续聊口径）。
  - 首页：`home_widgets._HomeTabBar`（新增 `state` 入参，`home_main_view` 透传）。
  - 我的：`mine_page._MineTabBar`（同上）。
  - 两个 tab **各画各的栏**，所以底栏改动永远是两处，别只改一处。
- 该格用 `if (kAiEntryEnabled)` 包着：关掉时整格不占位。小程序那边关掉是留空占位保住
  四栏 grid，App 这边胶囊是 `Row` 等分，删一格自然还是均分，不需要占位。
- 文案新增 `AppL10n.tabAi`（AI助手 / AI Assistant / AIアシスタント），
  与页内标题 `aiTitle`（AI生图）**不是同一个词**，别互相替换。
- 图标复用仓库里已有的 `assets/images/ai-tab.png`（`ai-tab-active.png` 暂无消费方：
  AI 页是 push 出去的，回来仍停在原 tab，中间那格没有「选中态」）。

底栏格数见下一节：本轮连同官方图库一起补齐，两端已是同一套四格。

### ⚠️ 开放前就挂着、现在仍挂着的账

- 网关 JWT（`Authentication: Bearer`，注意不是 `Authorization`）与 `/chat` 的 SSE 链路
  **从未在真机上验过**——`2026-08-07-AI流式SSE与JWT补齐.md` 明确要求开放入口前单验一次。
- 语音输入仍是占位按钮；「下载」只写应用缓存目录。
- 星币不足由服务端裁决（`chkAiDialogue`，403 + retMsg），App 无购买页，弹窗只有「知道了」。

真机验收不过就把 `kAiEntryEnabled` 改回 `false`，底栏会自动缩回两格。

## 4. 「我的」页底栏固定（需求 2）

**根因**：`mine_page` 把整页（含底栏）塞在同一个 `SingleChildScrollView` 里，底栏只是被
`Spacer()` 顶到 `Column` 末尾。屏幕够高时看着像固定在底部，一旦内容高过视口
（iOS 刘海/灵动岛机型安全区吃掉一截、或系统字号放大），底栏就跟着内容一起滚——
即反馈的「底部 tabber 栏和页面滚动融合到一起」。

首页 2026-08-05 已经踩过同一个坑并修好了（`2026-08-05-首页未绑定态样式错乱与滚动条修复.md`），
只是当时没顺手改「我的」。本轮把「我的」改成与 `_HomeMainView` 同一竖向结构：

```text
SafeArea
└ Column
  ├ Expanded(滚动区)          ← LayoutBuilder + SingleChildScrollView + ConstrainedBox(minHeight)
  └ 底部 Tab 栏 + 13 间距      ← 固定，永远在视口内
```

新外层 `Column` 必须写 `crossAxisAlignment: CrossAxisAlignment.stretch`：`_MineTabBar` 自己
不写宽度（不像首页的 `_HomeTabBar` 有 `width: double.infinity`），靠父级紧约束铺满；
用默认的 center 会让胶囊按内容缩成一小坨、滚动区也跟着缩宽。

顺带删掉 `IntrinsicHeight` 与 `Spacer()`：两者是一套的（`IntrinsicHeight` 只为让
滚动区里的 `Spacer` 有确定高度可分），底栏移出去后 `Spacer` 没了，`IntrinsicHeight`
也就只剩额外一趟固有尺寸测量。滚动区末尾补 13 的留白，内容顶到底时不贴着底栏。

页面里的卡片都自带确定高度（`_ProfileCard` 用 `AspectRatio 327:121`、`_FeatureCard` 是
`SizedBox(height: 148)`），不依赖外层 `IntrinsicHeight`，删掉不影响布局。

## 5. 微信授权成功提示（需求 3）

`auth_page._loginWithWeChat` 原来只在失败时弹提示（邮箱登录的口径：成功后根节点直接切主壳层，
界面变化本身就是反馈）。本轮给微信这条**开特例**：中途切去微信客户端再跳回 App，
回来时需要一句确认这趟走通了。

- 新增 `AppL10n.accWechatLoginSuccess`：授权登录成功 / Signed in with WeChat /
  WeChatでログインしました。
- 提示时机在**换到 `userToken` 之后**（`feedback.success` 分支），不是刚拿到 code 时。
  这样「微信授权成功但后端拒登」不会先弹一句成功再被错误提示顶掉（`AppToast` 同时只留一条）。
- 与平台无关：Android/iOS 走的是同一段 Dart 代码，不需要分端处理。
- toast 走根 Overlay（`AppToast` 用 `rootOverlay: true`），紧接着根节点把登录页换成
  `AppShell` 也不会把它带走。
