## 一、官方图库（新模块）

`lib/src/features/gallery/official/`（与既有的 `gallery/presentation/gallery_page.dart`
＝「我的相册」分开放，两者只是名字像，数据源与用途完全不同）：

| 文件 | 职责 |
| --- | --- |
| `official_gallery_api.dart` | 五个 `/Client/Product/*` 接口的归一层，对齐小程序 `utils/gallery-api.js` |
| `official_gallery_page.dart` | 图库列表：分类条（含端上补的「全部」）+ 右端固定「收藏」入口 + 瀑布流 + 上拉续页 |
| `official_gallery_detail_page.dart` | 详情：沉浸式大图 + 白卡（标题/收藏/简介）+ 贴底「开始投屏」 |
| `official_gallery_favorites_page.dart` | 我的收藏：同一套瀑布流，取消收藏后重拉 |
| `official_gallery_waterfall.dart` | 两列瀑布流（两页共用） |

字段口径与小程序逐条对齐（都是「接错了页面照样渲染、只是数据不对」的类型）：

- `productImgId` 是 integer；详情的简介字段叫 **`content`**（不是 desc）；
  收藏态是 **`isAlreadyCollected` 的 0/1**（不是布尔）。
- 列表是 `BasePageOutput`，判停**优先 `pageCount`** —— 只看条数会在「后端无视 pageSize
  按自己的默认值分页」时提前停。
- 「全部」分类是**端上补的**（`categoryId = 0`，列表接口不传该参数即全部）。

### ⚠️ 两处后端缺口，端上在兜（与小程序同款兜法，补齐后两端一起删）

1. **列表项没有图片宽高/比例**。瀑布流必须在渲染前占好高度（否则图陆续到达时会把下方卡片
   一路顶走、用户正看的那张跳掉），所以先按 3:4 占位，图片加载完再按真实宽高校正**那一张**。
   ⚠️ 校正**只改高度、不重新分列** —— 重排会把用户正在看的卡片整块挪走。
2. **列表项没有收藏态**（只有详情有）。红心要按收藏态显示实心/描边，所以另拉一页收藏列表
   （200 条）在端上标记；拉不到就一律描边，静默失败不打断浏览。

### 投屏走的是既有链路

详情页「开始投屏」＝ 权限门禁 → 连设备 → `RecastDownload.toTempFile` 把远程图下到本地 →
`CastPreviewPage` 构图 →「开始投屏」照常出帧 + BLE 图传 + 建记录。
与「我的相册」的再次投屏、投屏管理页的重投**同一条链路**，没有另起一套。
未连接时弹设备选择（对齐小程序 `devicePicker`）；只有一台已绑定设备时直接用它。

## 二、星币（新模块，**只读**）

`lib/src/features/star/`：`star_coin_api.dart` + `presentation/star_coin_page.dart`
（余额卡 + 记录入口 + **星币消耗规则表**）+ `presentation/star_coin_records_page.dart`
（购买/消费两个 Tab，分页）。

⚠️ **与小程序有意不同：App 侧没有「立即购买」**。小程序走微信虚拟支付，App 对应的是
Apple IAP / Android 内购，**尚未接入**。与其画一颗点了没反应、或者更糟——在后台留下一串
永远付不掉的待支付单的按钮，不如如实告诉用户「先去小程序买，余额在这儿看」
（`AppL10n.starPurchaseUnavailable`）。所以数据层**故意不实现 `addOrder`**。
IAP 接上后：把那句提示换成套餐卡 + 下单按钮即可，其余不动。

星币消耗规则表（`GET /Client/Order/getAiConfigList`）：`retData` 是**裸数组**（不是分页壳），
`aiProject`/`num`/`remark` → 服务类型/消耗/说明。**顺序原样保留**（后端按 grade 排好再下发，
Client 出参里没有这个字段，端上重排会和后台配置对不上）；`30.0` 显示成 `30`（星币整数计价）；
拉不到整块不渲染，不弹错也不留空白。

## 三、入口与资源

- 入口：「我的 → 服务与帮助」新增两行 —— **星币管理**、**官方图库**，排在操作指南之前。
  小程序里官方图库是底部 tab，而 **App 底栏只有首页/我的两格**，所以挂在这一栏。
- 路由：`AppRoutes.starCoin` / `AppRoutes.officialGallery`（收藏页与详情页要带参数，
  一律 `AppPageRoute` push，不给名字）。
- 图片：从小程序仓库同步了 `heart-solid` / `heart-outline` / `token-coin` /
  `primary-btn-bg` / `mine-icon-token` / `tab-gallery` 六张到 `assets/images/`
  （`pubspec.yaml` 已按目录声明，无需改）。收藏角标的**半透明白圆底是代码画的**，图里只有心。
- 文案：`app_l10n.dart` 新增两组 key（`gallery*` / `star*`），三语种齐。

## 已知风险（未编译，首次跑起来重点看这几处）

- **图片比例校正的时机**：监听挂在 `imageBuilder`（build 期间），图若已在缓存里会**同步**触发。
  已用 `addPostFrameCallback` 把回调推到当前帧之后 —— 否则就是 `setState() called during build`。
  卡片按 `ValueKey(photo.id)` 绑 State，切分类后「已量过」的标记不会串到下一张图上。
- **未接 IAP**：星币页只读，不要误以为漏做了购买按钮。
- 详情页大图/白卡按屏高百分比排版（58% / 55%），极扁的折叠屏展开态下白卡剩余高度会变小，
  简介很长时要滚一点。
- 官方图库的接口在 App 侧是**第一次调用**，`getProductImgList` 等是否需要登录态、
  未登录时的表现都未在真机上验过。
