# WiFi 详情「一键清空」随页面显示（main）

> 类型：Historical Implementation Record
> 日期：2026-11-14；环境：远程 SSH 服务器；分支：main；修改前：189ed8d
> 依据：产品要求设备详情的一键清空、解除绑定在页面加载时就显示，有逻辑限制时点击无效即可，不要加载完再过 1 秒才出现。同小程序同日改动。

## 原因

WiFi 详情页按设备列表的数据立即渲染，而「是否所有者」要另查设备详情（`_loadOwner`，约 1 秒）。查到之前 `_isOwner` 为 false，「一键清空」行不渲染，回来后才插进卡片。

## 改动

- `_buildActions`：「一键清空」行不再按 `_isOwner` 包裹，与解除绑定一起随页面显示。点击时 `_isOwner` 为 false 直接返回（接收者、或身份还没查到），所有者照常进清空流程。
- 页底「删除设备」仍仅所有者显示，本次未改。
- `test/wifi_tf_share_test.dart` 补源码断言。
