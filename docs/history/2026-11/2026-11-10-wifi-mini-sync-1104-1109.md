## 改动

### 轮播设置服务端化（对接文档 20261105 / 20261105-1）

- `wifi_strategy.dart` 重写（同小程序 `utils/wifi-strategy.js`）：时区 `timeZone` 必传；间隔 10 分钟起、结束可选 24:00、默认 00:00~24:00；
  去掉 idle；两组时间参数都带；简单模式启用开关（关闭不提交基础字段）；工作日 / 周末 / 纪念日高级卡片（[WifiStrategyCard]）；
  每 N 天 1~30（存量 > 30 提示、不让存）；纪念日只选月日、2 月最多 28 日；「下次刷新：MM-dd HH:mm · 卡片类型」；
  简单模式照片默认不选（保存过的 imgUrls=null 才回显全选）；保存后不再投第一张。
- 新增 `wifi_time_zone.dart`：候选时区与四语种「国家 / 城市」、分组搜索、手机时区推断。
- `WifiSlideshowPage` 重写：状态卡（设置时间、下次刷新、轮播方式、时区）、简单模式卡片、同页展开的高级设置；
  新增 `wifi_slideshow_sheets.dart`：时区弹层、选图弹层（每行 3 张、每页 21 张、滑到底显示下一页）、多列滚轮（结束时间、纪念日月 / 日）。
- `fetchSuccessCastRecords`：有完整设备 ID 时带 deviceId，按页 21 条取完（≤30 页）。

### WiFi 设备详情 / 删除 / 消息

- 删除设备：清相册记录 → photo/delete all=true → 新接口 `IotApi.restoreBuiltin`（restore-builtin，renderMode 同投屏）→ 删设备；
  restore-builtin 只有 401 / 403 停下，其余照常继续。
- 新增「一键清空」（仅所有者，两级确认，做删除设备前三步、保留设备记录），与「解除绑定」放进同款蓝牙版的操作卡片。
- 隐藏「休眠设置」入口（`WifiSleepPage` 保留）；消息中心未读只亮红点。
- 轮播中标记：只在 running 且在线时显示，图标换绿色版 `device-detail-icon01-on.png`，去掉「轮播中」文字（详情与我的设备）。
- 消息中心：列表带 `lang`（按 App 语种：zh-CN / zh-TW / en / ja），接口返回 title / content 直接显示，没给才本地兜底；
  新增消息类型 `CAROUSEL_NOT_SENT`。

### 共享设备

- 成员接口 `isCanDel == 1` 才显示「移除」；接收者自己那行在原位置显示「我」；移除自己走 `deleteDevice` 后回首页。
- 分享卡片封面：`wifi_share_card.dart` 用 dart:ui 画 5:4 邀请封面（标签 + 设备图 + 设备名 / 规格 + 接受按钮），
  画不出来或超过微信 128KB 上限时退回原设备图。

### 投屏

- WiFi 结果页：成功「继续投屏」（本页弹拍照 / 相册 → 同设备进预览页）/ 失败「重试未成功的」，第二个按钮「返回首页」；
  逐张列表文案跟阶段（上传中 / 处理中）、最多 4 行可滑、跟随当前张；相册记录与缩略图用原图（`originalPaths`，修复竖向 180° 机型倒置）。
- 蓝牙结果页：多张时逐张状态（等待投屏 / 处理中 / 已发送 / 传输中 / 投屏完成 / 投屏失败 / 已中断 / 未投屏，
  `ServerImageProjectionService.onItemStage`），最多 4 行；图传卡住提示改为「电子纸设备忙或处理不过来，请重新尝试」。
- 官方图库 / AI 生图点投屏一律弹设备选择框（所有已绑定设备都列出，行上带在线 / 已连接状态，蓝牙版也挂角标），按钮「投屏」。
- 投屏相关按钮防重复点击：新增 `shared/tap_guard.dart`（执行中忽略、结束后冷却 500ms、挂住 60s 兜底），
  接入首页拍照 / 相册、我的设备与详情「投屏」、WiFi 投屏入口、AI 投屏、蓝牙结果页继续 / 重新投屏。

### 我的设备 / 我的相册 / 搜索 / 配网 / 首页

- 我的设备：WiFi版 / 蓝牙版 Tab 切换（加号单独一行在上），当前 Tab 没设备显示默认图 + 加号、整块点击添加。
- 我的相册：每页 21 条、滑到底加载下一页；按设备查到的共享成员照片照常显示，删除 / 再次投屏按
  记录 userProductId → 完整设备 ID → 当前设备归属，跨设备才拦；删除写请求日志（`[相册删除]` / `[相册删除][WiFi]`）。

  搜索中雷达 gif 尺寸不变。
