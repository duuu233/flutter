> 对应小程序：`photo-album` main-wifi 分支 f336637 之后至 2ea6572（2026-10-27～28：休眠状态、协议 V1.4 对接、首页 / 列表订阅状态推送、休眠设置、消息中心、服务端反馈追加内容）

## 改动

### 接口层

- `IotClient.post`（JSON，不做网络重试）。
- `IotApi`：`play` 加 `refresh`（false 才带）与 `addToCarousel`（true 才带）；新增 `getStrategy` / `setStrategy` / `stopStrategy`（轮播）、`deletePhotos`（删云端 bin）、`getSleep` / `setSleep`（休眠）、`getNotifications` / `getUnreadCount` / `markNotificationsRead`（消息）。
- `BoltFoxApi.addWifiAlbumRecord`：投屏后 `setFileUpload` 拿 img + `addUserProductImgRecord` 写 img / imgBle（=binUrl）/ deviceUploadState=1，无槽位。⚠️ 不带 upirId / taskId 能否新建、能否按 userProductId 查回，待联调。
- `PhotoFrameState.deleteCastRecords` 多返回 `failedIds`；新增 `fetchSuccessCastRecords`（轮播选图用，不改「我的相册」列表）。

### 状态

- `WifiOnlineStatus` 加 `sleeping`（蓝色「休眠中」）/ `shutdown`（灰色「已关机」）；`wifiDeviceState` 认接口 / WS 的 `status`，缺失按 `online` 回退；只有在线才显示信号与电量。
- `wifiBlockedTip`：休眠「设备休眠中，唤醒后可操作」、关机「设备已关机，开机后可操作」、离线原提示；投屏入口、首页 / 图库 / 我的相册再次投屏的在线确认都按它拦。`wifiOfflineTipFor`：接口回 4041 时补查给对应提示。
- `WifiWatch`（同小程序 `utils/wifi-watch.js`）：首页、我的设备在页面可见时订阅列表里 WiFi 设备的 `device.status`，推送只重查那一台，长连接重连成功全部重查；进下一页退订、回来再订；只退订自己订阅的。不做定时轮询。

### 投屏（V1.4 更新说明第二节）

- `WifiProjection.projectOne` 重写：接口返回即结束（SENT「已发送，屏幕即将刷新」/ UPLOADED 只上传 / FAILED），不再等 WS `play.result`、不查状态、去掉 TIMEOUT 修正与 90 秒兜底；4041 补查休眠 / 关机；带回 `binUrl` 与 `carouselUpdated`；可选 `onLog`。
- WiFi 投屏结果页：多张时本轮最后一张 `refresh=true`、其余 `refresh=false`，重试同规则；每张成功后写相册记录，失败只注明「未存入我的上传」；非正式包页面下方有可复制的投屏日志。
- 投屏预览页：WiFi 版进页查轮播，`running` 时在「开始投屏」上方显示「同时加入轮播」开关（默认关）；打开后结果页每张带 `addToCarousel=true`，有一张 `carouselUpdated=false` 就追加「未成功加入轮播，请前往轮播设置添加」。

### 新页面

- `wifi_slideshow_page.dart` 轮播设置（逻辑 `wifi_strategy.dart`）：间隔 / 固定时间、顺序 / 随机、轮播后休眠；从「我的相册」这台设备的成功记录（带 imgBle）选图，按选择顺序作 `imgUrls`；回显 `null` 全选、`[]` 提示重新选择；不选不让存，按相册顺序全选不带 `imgUrls`；上限 100（「已选 X/100」、选满置灰并提示、全选只选前 100、回显全部相册超过 100 只选前 100 并说明、4000 明确提示）；保存后立即下载第一张 `refresh=true` 投屏（不写新记录）；轮播中可暂停。
- `wifi_sleep_page.dart` 休眠设置（逻辑 `wifi_sleep.dart`）：回显当前计划；关闭（确认）/ 周期（可跨午夜，不能相同）/ 一次性（开始早于结束、结束未过）；只传本地时间；4041 补查、4000 显示服务端字段；保存后重查。
- `wifi_messages_page.dart` 消息中心（逻辑 `wifi_messages.dart`）：每页 20 条、下拉刷新、滑到底加载（按 id 去重）、只看未读、type 翻译 + payload 关键参数、未知 type 通用文案；单条已读回传原始 id（失败回滚）、全部已读传空数组；`notification.new` / 重连成功 500ms 合并刷新；403 单独提示。
- 时间 / 日期 / 选项选择器、分段、表单行放在 `wifi_widgets.dart`（App 之前没有选择器组件，用 Material `showTimePicker` / `showDatePicker` 与底部列表）。

### 页面调整

- WiFi 设备详情：操作栏「刷新状态」改「轮播设置」；新增「休眠设置」「消息中心」入口，消息中心带未读角标（进页、从消息中心返回、收到本设备 `notification.new` 时查，超过 99 显示 99+）；状态行认休眠 / 关机。
- 我的设备：WiFi 卡按钮改「投屏 | 轮播设置」；两类卡名称下加「尺寸 · 设备ID xxx」（没配尺寸显示「--寸」）；WiFi 卡认休眠色。
- 首页设备卡：名称下加「WiFi版 / 蓝牙版·尺寸」标签（没配 --寸）；两类卡的状态与电量排同一行（蓝牙卡未连接时下方仍是「连接蓝牙」）。卡内左右居中本就按 space-around 实现（2026-09-03），未改。
- 我的相册：WiFi 版照片删除不连蓝牙——先删老服务记录，再把真删掉的记录的 imgBle 交 `deletePhotos`（每批 200）+ `nextImageUrl`（剩下第一张）；确认弹窗多一句「删除后相框可能需手动切换才会更新。」；提示按 deviceAction / deviceNotified：切到下一张、设备离线、部分失败、云端失败，其余「已删除；若相框未更新，请手动切换或重新设置轮播」。再次投屏：确认在线后下载原图进预览，不连蓝牙。
- 绑定默认昵称改为完整蓝牙广播名（`BleController.fullBroadcastName`：platformName / advName 取长的），WiFi 版与蓝牙版同口径；广播名取不到才回落产品名。
- 选择 WiFi 页去掉顶部「设备仅支持 2.4G WiFi 配网」提示条，列表标题改「设备附近的WiFi」（列表仍只留 2.4G；账号密码页提示未动）。
- 文案全部在 `wifi_l10n.dart`，简中与小程序逐字一致，英 / 日新译，繁中自动转换。
