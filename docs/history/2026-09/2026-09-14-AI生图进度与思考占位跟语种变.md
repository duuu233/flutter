# AI 助手：生图进度文案与「思考中」占位跟语种变

> 文档类型：Historical Change Record
> 日期：2026-09-14
> 环境：SSH（本机无 Flutter SDK）
> 分支与起始版本：main / `170412b`
> 范围：`lib/src/shared/l10n/app_l10n.dart`、`lib/src/features/ai/presentation/ai_chat_page.dart`、`test/ai_generation_copy_l10n_test.dart`
> 相关规则：`AI_CONTEXT.md` 第 11 条；上一轮 `docs/history/2026-09/2026-09-11-AI助手标题不跟语种变.md`

## 现象

产品：AI 助手模块在英文或其它语种下，页面标题「新对话」、生成内容时的「初稿已完成」等仍是中文；
要求检查 AI 助手模块的文案是否都根据 App 设置的语种动态变化。

## 核对结论

逐个扫了 AI 模块（`lib/src/features/ai/**`、`boltstar_ai_api.dart`、`ai_service_consent.dart`，以及聊天页
用到的设备选择弹层、低电量提示、投屏预览）里**去掉注释后**所有含中日文的字符串字面量：

| 项 | 结论 |
| --- | --- |
| 顶栏 / 会话列表「新对话」 | **已修**（2026-09-11 `858ad7d`）：后端写死的简中占位跨语种识别，build 时按当前语种取 |
| 弹框、toast、空态、欢迎页、工具栏、错误码文案 | 已走 `AppL10n` / `AiI18n`，build 时取；`AiI18n` 25 个码四语种齐全 |
| **生图进度文案**（「初稿已完成 ✨」「正在优化细节…」等） | **没做**：`ai_chat_page.dart` 顶部一张写死的简中 stage 表；而且服务端 `progress.message`（也是简中）优先上屏；算好的文案还**存进了消息对象**，途中切语种不重算 |
| **第一条 `pre_text`「星宝努力思考中」** | **没做**：服务端写死的简中，原样上屏 |
| 其余含中文的字面量 | 均为 `debugPrint` 日志，不上屏 |

BoltStar 接口约定「后端不返回面向用户的文案，文案由前端 i18n 管理」，请求里也没有语种参数，
所以这两处只能端上处理。

## 变更内容

1. `AppL10n` 新增：`aiProgressConnecting / Creating / DraftReady / Refining / Downloading / Done`、
   `aiThinkingPlaceholder`（英文里星宝叫 Stella），以及 `isThinkingPlaceholder(String?)`——
   认服务端两种写法「星宝努力思考中」「星宝努力思考创作中」和任意语种自己的写法，
   忽略首尾空白与结尾省略号，**完全相等才算**（LLM 写的「星宝努力思考中，马上为您画…」不误吞）。
2. `ai_chat_page.dart`：
   - 删掉写死的简中 stage 表；`aiProgressLabel(l10n, progress, stage, message)`：**简中 / 繁中**仍用服务端
     `message`（繁中经 `pick` 转繁，保留「改文案不用发版」），**英文 / 日文**不看 `message`，按 stage →
     `AppL10n`，没有 stage 时按原数值分档；
   - `_AiMessage.progressLabel`（算好的字符串）换成 `progressStage` / `progressMessage`（原料），
     渲染时按当前语种现算，生成途中切语种文案当场跟着变；
   - `_buildPreText` 渲染时认出占位换成当前语种。
3. `AI_CONTEXT.md` 第 11 条补一段：BoltStar 会推写死的简中（标题占位、思考占位、进度 message），
   端上识别、build 时本地化、不存算好的字符串。
4. 新增 `test/ai_generation_copy_l10n_test.dart`。

## 关键决策

- **中文语种保留服务端 message**：原设计是文案归后端管；只在后端给不了的语种上绕开它。
- **不本地化 LLM 写的内容**（回复正文、真预描述）：它跟着用户输入的语言走，端上管不了也不该改。

## 验证结果

- 本机无 Flutter SDK，`dart analyze` / `flutter test` **未执行**，新用例未运行。
- 借用花盆仓库的静态检查脚本跑本仓：`dart_string_check.py`、`dart_dangling_refs.py` 均 OK（163 个文件）。
- 真机未验：需在英文 / 日文 / 繁中下走一遍「一键生图」，看占位盒进度文案与橙色预描述胶囊，并在生成中切语种。

## 未完成项与风险

- 服务端若改了占位原文（第三种写法），`isThinkingPlaceholder` 认不出会再次原样显示中文；需要后端改动时同步这张表。
- 小程序（photo-album）是否有同样问题本轮未查、未改。
