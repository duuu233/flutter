# 启动页 slogan 改为「呈现美好」并接入多语言（2026-09-16）

> 状态：**已改**，⚠️ **未编译未真机**（本机无 Flutter SDK，`dart analyze` / `flutter test` 均未跑）
> 适用范围：**仅 App 端**，两个文件：
> `lib/src/features/shell/presentation/splash_page.dart`、`lib/src/shared/l10n/app_l10n.dart`
> 需求原文：「APP启动页下面的文案『把美好，留在一张纸上』替换成 简中：『呈现美好』，
> 英语：『Present Beauty』，繁体和日语你自己补充一下，根据原有语言设置规则，自适应展示。」

## 一、改前：硬编码，不跟语种走

`splash_page.dart` 里是一句写死的中文：

```dart
child: const Center(
  heightFactor: 1,
  child: Padding(
    padding: EdgeInsets.only(top: 16),
    child: Text('把美好，留在一张纸上', …),
  ),
),
```

无论用户把语种设成英文还是日文，闪屏都显示这句中文。

## 二、改后：走 `AppL10n`

`app_l10n.dart` 新增一条（放在「通用」之前的新分组「启动页」下）：

```dart
String get splashSlogan => _pick('呈现美好', 'Present Beauty', '美しさを映す');
```

`splash_page.dart` 改为 `AppL10n.of(context).splashSlogan`，并把外层的 `const Center` 去掉
（内部要用 `context`），`EdgeInsets` 与 `TextStyle` 各自补回 `const`。

### 四个语种的取值

| 语种 | 文案 | 来源 |
| --- | --- | --- |
| 简体中文 | 呈现美好 | 需求给定 |
| English | Present Beauty | 需求给定 |
| 日本語 | 美しさを映す | 本轮补。`映す` 兼有「映现 / 显示」之意，贴合电子纸相框「把照片呈现出来」的语义，长度也与中英两版的简洁感一致 |
| 繁體中文 | 呈現美好 | **不单独给**，见下 |

### 繁中为什么不写死

`_pick(zh, en, ja, [zhHant])` 的第四个参数缺省时会走 `toTraditionalChinese(zh)`
（`app_l10n.dart` 第 50 行）。对「呈现美好」这四个字：

- 「现」在字表里 —— `chinese_script.dart:309` 的 `0x73B0: 0x73FE // 现 -> 現`；
- 「呈」「美」「好」三字繁简同形，字表中没有条目，按原字保留。

所以自动转换的结果**正是**「呈現美好」，与项目里多数 `_pick` 只给三个参数的惯例一致，
不必为它单开一条繁中文案。

## 三、为什么闪屏能拿到语言

`AppLocalizationsScope` 挂在 `MaterialApp.builder` 里包住 `child`
（`bolt_star_app.dart:514`），而闪屏是 `home` 的一个分支（同文件 466 行的 `_showSplash`），
在 Navigator 之内 ⇒ 在 scope 之内，`AppL10n.of(context)` 正常工作，切换语种也会整页重译。

## 四、原生冷启动图不用动

Android `android/app/src/main/res/drawable/launch_background.xml`（含 `-v21` 副本）与
iOS `ios/Runner/Base.lproj/LaunchScreen.storyboard` 都**只有背景图与 LOGO、不含任何文案**
（storyboard 里 label/text 节点数为 0）。所以这句 slogan 只在 Flutter 首帧出现，
改 `splash_page.dart` 这一处即可，不存在「原生图上还留着旧文案」的问题。
