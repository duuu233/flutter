# 繁体中文支持核对：转换表补齐（AI 模块为主）

> 文档类型：Historical Change Record
> 日期：2026-09-14
> 环境：SSH（本机无 Flutter SDK）
> 分支与起始版本：main / `8666204`
> 范围：`lib/src/shared/l10n/chinese_script.dart`、`lib/src/features/devices/presentation/ota_upgrade_page.dart`、`test/traditional_chinese_conversion_test.dart`
> 当前权威文档：`AI_CONTEXT.md`「Traditional Chinese is generated, not translated」

## 背景

产品：检查繁体语种是否都已支持，特别是 AI 模块，以前可能漏了繁体。

## 核对方法与结论

### 1. 繁中文案怎么来的

除 `AiI18n`（AI 错误码、一键生图消息）手写了繁中外，全站繁中都是简中源文案经 `toTraditionalChinese`
现转：先按词表替换，再按单字表逐字转。字表是手写的约 400 字——**不在表里的简体字会原样显示**。

### 2. 用 OpenCC 台湾标准逐段比对

从 `lib/` 抽出所有会被转成繁中的简中源文案：`_pick` / `pick` 首参、`tr(zh:)`、`AppL10n._serverMessages`
（后端 retMsg 兜底表）首项，以及固件升级失败细节（`ota_ble` / `ble_controller` / 帧协议里的中文，中文语种
原样展示）。共 919 段。在内存里读 OpenCC 的 `STCharacters` / `STPhrases` / `TWVariants`（GitHub 原始文件，
未落盘），按 s2tw 做最大匹配转换，与按 Dart 同一算法模拟的 App 转换结果逐字比对。

发现（修之前）：

- **界面文案 772 段里有 180 段在繁中下仍夹着简体字**，涉及 55 个字；其中 **AI 模块 112 段里有 34 段**
  （欢迎语「星宝 / 伙伴 / 什么 / 吗」、「松开发送」「没听清」「麦克风」「客厅」、比例「竖向 / 横向」、AI 服务协议的
  违、议、许、诺、秽、胁、骚、誉、诉、医、咨、赖……）；全站高频的是「纸」（电子纸）、称、络、昵、阅、点、访等；
- **三处转错**：`0x6D4F`（浏）被注释成「济」并映射到「濟」→ 浏览器变「濟覽器」；`0x8D5E`（赞）被注释成「赏」
  并映射到「賞」；「复」一律转「復」→ 复制变「復制」；
- 固件升级失败细节 147 段里 27 段有同样问题（其中 7 个字 丢 却 坏 砖 绪 筛 缓 与 2 个词是界面文案里没有的）；
- `AiI18n` 的手写繁中 32 段未发现简体字，25 个错误码四语种齐全。

### 3. 其它检查

| 项 | 结论 |
| --- | --- |
| 语种设置、持久化（`zhHant`）、系统语言（Hant / TW / HK / MO → 繁中） | 已支持 |
| 后端 `language` 头 | 繁中 = 3，已支持 |
| Material 内建文案 | `supportedLocales` 含 `zh-Hant` |
| AI 语音识别 locale | 繁中有 `zh_tw` / `zh_hk` / `zh_hant` 候选 |
| AI 生图进度服务端文案 | 中文语种经 `pick` 转繁（上一轮 `8666204`） |
| 固件升级失败细节 | **原来繁中原样给简体**，本轮改为经 `pick` 转繁 |
| iOS 系统权限弹框文案（`Info.plist`） | **没有任何 `.lproj` 本地化**，所有语种都是简中——本轮未改 |
| 未走多语种的中文字面量 | 大部分是调试页、日志、协议对照表或显示时再映射的 key；启动页标语、离线兜底 FAQ 等在所有语种下都是简中，属全语种问题，本轮未改 |

## 变更内容

1. `chinese_script.dart`：单字表补 48 个只有一种繁体写法的字；修正 `0x6D4F`（浏→瀏，另把济→濟放回 `0x6D4E`）、
   `0x8D5E`→`0x8D4F`（赏→賞）；词表补 26 个一字多繁的词（注册、注销、联系、复制、这里、记录里、设置里、伙伴、松开、
   余额、剩余、占位、占用、尽量、日志、适当、适时、轻松、规范、范围、采取、局限、咨询、尝试、特征、重发里）。
   有意不转：了解、发布、公布（台湾通行写法）。
2. `ota_upgrade_page.dart`：失败细节对繁中经 `l10n.pick` 转繁。
3. 新增 `test/traditional_chinese_conversion_test.dart`；`AI_CONTEXT.md` 补繁中生成方式与复核要求。

复核：改后 919 段与 OpenCC s2tw 结果**全部一致**（除上述有意保留的三个词）；字表 456 条无重复键、注释与码点一致。

## 验证结果

- 本机无 Flutter SDK，`dart analyze` / `flutter test` **未执行**，新用例未运行；测试期望值由按 Dart 同一算法的
  Python 模拟算出。
- 借花盆仓库 `dart_string_check.py` / `dart_dangling_refs.py` 跑本仓：OK。
- 真机未验：需切到繁體中文走一遍 AI 助手（欢迎页、按住说话、比例浮层、生图进度、AI 服务协议）与「我的」相关页面。

## 未完成项与风险

- 字表方案天生会漏：以后新增含生僻字的简中文案，需按上面的方法再比对一次。
- 词汇是「字转繁」，不是台湾用语本地化（如「网络」→「網絡」而非「網路」、「设置」→「設置」而非「設定」）；
  如需台湾用语，要另开需求逐条定。
- iOS 权限弹框多语种、启动页标语等全语种硬编码中文未处理。
