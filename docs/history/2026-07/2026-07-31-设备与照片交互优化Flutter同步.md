## 逐项实现

### 第 1 项 · 设备命名

- 新增 `lib/src/shared/widgets/device_name_dialog.dart`：小程序 `components/device-name-dialog`
  的 Flutter 版，顶部相框+笔标记、居中标题与副标题、带 `n/20` 实时计数的输入行、取消/保存双键。
  三个入口共用：我的设备列表、设备详情摘要卡、**绑定成功后的命名引导**。
- 长度上限按 **Unicode 码点** 计 20 个：`kDeviceNameMaxLength` + `_RuneLengthLimiter`
  （Flutter 自带的 `LengthLimitingTextInputFormatter` 按 UTF-16 码元截断，一个 emoji 占 2 个，
  20 字上限只能打 10 个 emoji，还会把代理对截成半个字符）。
- 绑定成功后（**仅新绑定，复用已绑定记录的路径不进**）在绑定页弹出带默认名的命名弹窗；
  点「保存」调 `renameDevice`（带保存中 loading），点「暂不修改」直接按原逻辑返回。
  拿不到后端记录主键时静默跳过——没有 id 就调不了改名接口。
- 长名称省略：首页设备卡与切换弹层、设备列表卡、设备详情摘要卡、图库/投屏记录设备下拉，
  逐处复核均为单行 `TextOverflow.ellipsis`（本轮无需新增）。

### 第 3、10 项 · 设备照片页

- 标题 `galTitle` 由「我的图库」改为「设备照片」。
- 工具栏下方新增说明条 `_ScreenPhotoHint`（小程序 `.album-hint`）：橙点 +
  「当前屏幕照片，可指定显示或删除当前屏幕照片」。有照片与空态两条分支都渲染。
- 设备下拉加宽：胶囊 `min 88→112 / max 170→200`；菜单由钉死的 `105` 改成
  `IntrinsicWidth + 140~240` 夹取（等价于小程序的 `width: max-content` + min/max）。

### 第 4、14 项 · 照片预览

- `_kLongPress` 1000ms → **500ms**，`castEditHint` 四语种文案同步改「长按0.5秒」。
- `_clampTransform` 去掉两道夹取（① zoom ≥ cover ② 平移不越出图片），只留
  `_kMinZoomFactor(0.02) ~ _kMaxZoomFactor(8)`：图片可任意缩小、可在画布中自由构图。
- 取景框底色与轮播底色由 `#E6ECF4` 改为**白色**，与 `_bake` 导出前铺的白底一一对应——
  缩小露出的白边就是最终写进设备的那块白（所见即所得）。
- 切图过场 `_kSlideDuration` 300ms → **360ms**，与小程序 swiper 的 Banner 过场同时长。

### 第 5 项 · 昵称 emoji

- 新增 `lib/src/shared/display_text.dart` 的 `decodeDisplayText`：把后端历史数据里的
  `\uXXXX` / `\u{XXXXX}` / `&#123;` / `&#x1F31F;` 四种转义还原成真实码点，
  在 `_applyUserInfo` 写入昵称时解一次。具名实体（`&amp;` 等）**不解**——
  昵称里出现它更可能是用户真的打了这几个字符。

### 第 6 项 · 我的设备排序与切换动效

- 新增 `lib/src/device/recently_bound_device.dart`（对齐小程序 `RECENTLY_BOUND_DEVICE_KEY`）：
  绑定成功时记一条 `userProductId`；解绑这台 / 退出登录 / 注销 / 会话失效时清除。
- `devices_page.dart` 排序：**已连接 → 最近绑定 → 接口原序**（稳定排序）。
  连接态取 `isDeviceActuallyConnected`，不看后端记录里的缓存字段。
- 切换连接设备时给新连上那台一次上移入场动效 `_PromotionTransition`
  （520ms，16px 上移 + 58% 处轻微过冲，复刻小程序 `@keyframes devicePromoted`），
  560ms 后清除标记。

### 第 7 项 · 轮播设置误报「请先连接设备」

两处根因，都已修：

1. `refreshDevices` 里 `device.connected = _sessionMatches(device)` 排在
   `_carryOverBleFields`（本地上一版身份）与 `_completeDeviceIdentities`（登记表）**之前**——
   身份还没补齐就先判连接，刷新一次列表正连着的设备就整体掉成「未连接」。已调整为身份补齐后再判。
2. 新增 `PhotoFrameState.resolveDeviceConnected`：入口门禁先查身份登记表把完整 6 字节 ID
   填回记录再重判（等价小程序 `activeDevice.inheritStableIdentity`）。
   轮播设置、一键清空、删除设备三个入口的连接判定都改走它。

### 第 8 项 · 设备端已删除的照片仍可在图库删除

- `deleteAlbumPhotos` 新增 `devicePhotoAbnormal` 分支：**一条槽位都解析不出来**，
  或设备明确回「照片不存在」（`_isMissingDevicePhotoError`，口径同小程序
  `isMissingDevicePhotoError`）时，**继续删后端记录**，最后提示
  「照片在此设备异常，请删除重新上传」。
- 只放行这一类；断联、超时、设备繁忙等真实链路错误仍中止，避免设备没删掉却删了记录。
- `ActionFeedback` 新增 `warn` 位：「删成功但结果不理想」（照片异常 / 刷屏失败）走
  `AppToast.warn`，与两端 toast 语义约定一致。

### 第 9 项 · 设备详情文案与两条删除流程

- 「分辨率」→「屏幕尺寸」，图标换成新画的 `_ScreenSizeGlyph`（CustomPaint 1:1 复刻小程序
  `device-detail-screen-size.svg`；不为一枚图标引入 `flutter_svg`）。
- 「设备内存」→「最大照片数量」；「一键清空」右侧取值改「清空设备及设备照片记录」。
- 一键清空第一步提示改为「将清空彩色墨水屏设备内所有照片，同时清空小程序/APP的图库，
  请谨慎选择是否继续。」，按钮改「再想想 / 继续」。
- 原「删除设备」拆成两行：
  - **解除绑定**（保留设备上的照片）：一次确认 → 解绑，不再要求先手动断开
    （`deleteDevice` 内部就会断开占用的会话）。
  - **删除设备**（放在最底部，值文案「清空照片并解除绑定」）= 一键清空 + 断开 + 解除绑定，
    需已连接（未连接直接提示「请先连接设备」），两道二次确认：
    ①「如果您不再使用设备，建议执行一键清空设备照片，防止隐私泄露」取消/继续 →
    ②「我已知晓删除设备相关内容，确认删除」取消/确认。清空失败即中止，不解绑。
- `device_clear_flow.dart` 抽出 `runClearDeviceMemory`（只做 loading + 调用 + 失败提示），
  供删除设备流程复用，避免再弹一遍清空的两步确认。

### 第 11、12、15、17 项

### 第 13 项 · 投屏记录按设备筛选

  （`DeviceFilterOption` / `DeviceFilterChip` / `deviceSerialTail` /
  `disambiguateDeviceFilterLabels`），图库与投屏记录两页共用，样式天然一致。

## AI 样式优化同步

小程序 07-31 的三个 AI 样式提交（`be07154` 会话滑动删除、`157f641` 返回键/历史入口/Token
胶囊/浮层定位、`9006612` 方向按钮尾图标）逐条比对后，Flutter 侧此前已对齐绝大部分，
本轮补齐剩余两处：

- 方向按钮尾部图标 17 → **11**（小程序 34rpx → 22rpx）：原尺寸压过了左边的比例图标。
- 「重新生成」按钮的 `↻` 加固定 18×18 居中盒（小程序 `.retry-placeholder`）：
  字形在行盒里本身偏上，不框住会把按钮里的文字顶偏。

不适用 Flutter 的两条已记录原因：

- `.bubble--image .img-box { width: 100% }`：小程序是图盒写死 400rpx 而内容区 410rpx；
  Flutter 侧图本来就填满父约束，无此问题。
- `page-nav` 返回键换 `ai-back-button.png`：Flutter `FigmaBackButton` 早已是这张图，
  且 62px 画布 + 5.15% 下推的几何补偿完全一致。

## 影响边界

- 不改 BLE 协议、帧尺寸、设备物理分辨率与图传链路。
- 不改后端接口与参数，只新增 `refreshCastRecords` 已有的 `userProductId` 入参的调用。
- 预览页导出铁律（两方向恒导出竖向设备物理分辨率、横向整幅转 270°）**未动**。
