# BoltStar AI 服务协议与按用户授权

## Background

文本对话、文生图和用户图片美化会把用户主动提交的文字或图片传输给阿里云百炼处理。App 与微信小程序需要在首次使用前明确告知，并保证拒绝后不会把内容发送到第三方 AI 服务。

## Solution

- `AiChatPage` 首次进入时展示多语种“BoltStar AI服务协议”确认框。
- 拒绝不会禁用输入和历史浏览；普通文字、图文多模态与一键生图发送时继续弹出引导。
- `AiServiceConsent` 按“协议版本 `2026-07-28` + BoltFox 用户 ID”写入 `SharedPreferences`。
- `PhotoFrameState.logout`、`deleteAccount` 成功后、`_handleSessionExpired` 清除当前用户同意记录。
- 设置页新增 `AiServiceAgreementPage`，复用隐私政策/用户协议的 `LegalDocumentView`。
- `AppL10n` 提供简中、英文、日文文案，繁中沿用简转繁机制；完整协议正文四语种可切换。

## Cross-client Alignment

- 小程序使用 `utils/ai-service-consent.js` 和按用户 ID 的 Storage 映射。
- App 使用 `AiServiceConsent` 和按用户 ID 的 SharedPreferences 键。
- 两端首次进入、拒绝后的发送行为、退出/注销清理、协议日期、阿里云百炼数据说明和设置入口一致。
- 平台弹窗与本地化实现不同，但产品结果一致。

## Risks and Verification

- 发布前需分别用简中、繁中、英文、日文检查弹窗和长协议页面。
- 用 A/B 两个账号验证同意记录不串号。
- 验证退出、注销成功及登录态失效后重新登录都会再次弹出。
- 验证普通文字、文生图和上传图片处理都不能绕过发送前授权检查。
- 数据“不存储、不用于模型训练”和封禁规则属于产品/法务口径；若有变更需同步两端正文并提升协议版本。
