## 已同步

### 完整设备身份

- 新增完整 6 字节 ID 校验和 `AA:BB:CC:DD:EE:FF` 规范化。
- 拒绝广播 4 字节短 ID、全 0、全 F、非十六进制和长度错误值作为稳定身份。
- 广播短 ID 仅用于扫描候选；绑定判重/入库、后端记录、会话认领和连接后验身只认
  完整 ID 精确相等。
- 历史短 ID 后端记录不再按名称或短 ID 兼容，连接时明确提示删除后重新绑定。

### 电量

- 页面电量改为独立 `0x04` 数据源，不再把 `0x01` 电量写入页面状态。
- 同一完整设备 ID 的读数缓存 15 秒；过期后台刷新；并发请求合并。
- `0..100` 全部有效，包含真实 `0%`。
- 失败/非法响应保留最近有效值；从未成功读取显示 `--`；断开时隐藏。
- 设备列表整体刷新继续搬运最后有效值和读取时间，避免跨页面闪回未知。

### 已存在、仅核验

- 再次投屏已是“服务器图片 → 预览编辑 → Seekink 新帧 → BLE → 新记录”同一主链，
  无历史 `imgBle` 直传回退。
- Seekink 转帧 401 已强制 `isNewLogin=1` 刷新一次并只重试一次。
- 投屏预览常驻编辑、多图状态、横向 270° 写入竖向画布、JPEG 92% 和 1 秒长按已存在。
- AI 首次发送建会话、发送去重、历史并发补齐、图文同气泡和错误码分层已存在。
